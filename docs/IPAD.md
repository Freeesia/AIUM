# iPad 対応

## 構成

- `AIUM`、`AIUMWidget`、`AIUMTests` は端末ファミリー `1,2` の共通ターゲットです。
- 最低対応 OS は iOS / iPadOS 18.0 です。
- iPad の縦・上下反転・左右の横向きを許可し、全画面表示を強制しません。
- ダッシュボードは表示幅と文字サイズに応じて1列・2列を切り替えます。利用状況カードも狭い幅に合わせて縦配置・折り返しを使用します。
- 認証・設定・自動更新・ウィジェットの App Group は iPhone と同じ実装を使用します。

## テスト

```sh
xcodegen generate
xcodebuild test -project AIUM.xcodeproj -scheme AIUM \
  -destination 'platform=iOS Simulator,name=iPad Pro 13-inch (M5)' \
  -parallel-testing-enabled NO
```

シミュレータ名は利用可能な iPad に合わせて変更してください。Keychain と App Group を含むテストのため、シミュレータでも署名は既定のまま有効にします。

`.github/workflows/ipad.yml` は利用可能な iPad シミュレータを選び、アプリ・ウィジェットをビルドしてテストを実行します。

## 手動確認

デモモードでダッシュボードを開き、次を確認します。

| 操作・状態 | 確認内容 |
| --- | --- |
| 全画面で縦・横・上下反転 | 見出し、カード、設定・更新ボタンが表示領域に収まる |
| Split View やウィンドウ表示で幅を変更 | 幅に応じて1列・2列に切り替わり、使用量・時刻を読める |
| 文字サイズを拡大 | アクセシビリティの文字サイズでは1列となり、末尾までスクロールできる |
| 設定シートを開いたまま回転・幅変更 | シートと入力内容を維持し、完了ボタンを操作できる |
| 表示項目・更新間隔を変更してシートを閉じる | ダッシュボードに設定が反映される |
| リセット確認シートを開く | 対象アカウント・有効期限・操作ボタンが収まる。実際の消費操作は検証に含めない |
| ホーム画面・ロック画面のウィジェット | サイズ・サービスの選択と、アプリの取得結果の表示を確認する |

App Store への提出時は iPad 用スクリーンショットも用意します。既存の iPhone 用スクリーンショット変換スクリプトは使用せず、対象 iPad の表示サイズで撮影してください。
